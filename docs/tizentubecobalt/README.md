# TizenTube Cobalt — Overview

**TizenTube Cobalt** is an Android app based on [Cobalt](https://cobalt.dev) that brings
ad-free, sponsor-free streaming to a wider range of devices — including those that cannot
run TizenBrew.

> **Source:** <https://github.com/reisxd/TizenTubeCobalt>  
> **Author:** Reis Can  
> **Platform:** Android / Google TV (not a TizenBrew module)  
> **AFTVNews code:** `6366500`

---

## What Is Cobalt?

Cobalt is a lightweight, cross-platform HTML5 application container originally developed
by Google for embedded and resource-constrained devices (smart TVs, set-top boxes, game
consoles). TizenTube Cobalt packages the TizenTube experience inside this runtime, making
it available on Android and Google TV devices.

---

## Features

- **Ad Blocker** — removes all ads from the streaming experience.
- **SponsorBlock Support** — automatically skips sponsored segments.
- **Video Speed Control** — adjust playback speed to preference.
- **DeArrow Support** — removes clickbait thumbnails and titles.

---

## Installation

1. Download the [latest release](https://github.com/reisxd/TizenTubeCobalt/releases/latest)
   for your platform.
2. Sideload or install the app on your device via a file manager, ADB, or
   platform-specific method.
3. Open the app and enjoy.

> **Note:** TizenTube Cobalt is **not** a TizenBrew module. It is a standalone Android
> app. For Samsung Tizen TVs use [TizenTube](../tizentube/README.md) instead.
