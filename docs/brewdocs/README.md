# BrewDocs — Overview

**BrewDocs** is an unofficial wiki for TizenBrew and its ecosystem. It is built
as a TizenBrew module so you can read the documentation directly on your
Samsung TV without leaving the TizenBrew dashboard.

> **Source:** <https://github.com/axelnanol/brewdocs>  
> **Author:** Axel Nanol  
> **Module type:** `mods`

---

## Installing BrewDocs as a TizenBrew Module

1. Open TizenBrew on your Samsung TV.
2. Select **Add Module**.
3. Enter `axelnanol/brewdocs` and confirm.
4. BrewDocs will appear in your TizenBrew dashboard.

That's it — the wiki is now available on your TV. Use the colour buttons and
directional pad to navigate between pages.

For general module installation guidance, see
[TizenBrew Module System](../tizenbrew/Modules.md).
